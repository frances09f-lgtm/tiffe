Tiffe Staff 1.0.7 adds an in-app Update button for every staff role. Open the menu (owner and kitchen) or the top bar (delivery) and tap Check for updates. The app reads the update feed, shows the installed and latest version, downloads the APK inside the app with a progress bar, and opens the Android installer. It does not open a browser. Android asks once to allow installs from this app.
Order status now changes only when staff tap a status. The Auto-Accept switch is removed and the owner session switches the server auto-accept setting off.
The Upcoming list in Live Kitchen and newest-first All Orders from staff-v6 are kept. Payment, login and role code are unchanged.
Install this version by hand once. Later Staff releases arrive through the Update button.
Not tested on a phone. Analyze, the full test suite and the signed build passed in CI before publishing.
